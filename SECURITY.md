# Sicherheit

Bitte melde Schwachstellen **vertraulich** über [GitHub Private Vulnerability Reporting](https://github.com/Padrio/diskussionsanalyse/security/advisories/new). Veröffentliche weder API-Keys noch private Seiteninhalte in Issues oder Pull Requests.

Unterstützt wird der aktuelle Stand von `main`. Es gibt derzeit kein signiertes Firefox-Release und keine Zusage für ältere Versionen.

Der eigene Anthropic-Key wird im lokalen Erweiterungsspeicher abgelegt. Die Vorschau nutzt Anthropic zur Tokenzählung und überträgt dafür Seiteninhalt bereits vor dem Start der eigentlichen Analyse.
